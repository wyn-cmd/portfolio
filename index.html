Projects worth a look

Everything I build is public on GitHub, from a two-factor AES-256 vault to a pipeline that turns raw authentication logs into an attacker timeline. These are the ones I would walk through in an interview.

An AES-256 file encryptor that requires two separate passwords before it will decrypt anything, so a single leaked secret is not enough to open the vault.

Security Python AES-256

authlog-sessions

Reconstructs what an attacker did from Linux authentication logs: the connections behind the login attempts, the addresses that made them, and what ran after one of them finally worked.

Forensics Python Log analysis

A lightweight IDS for Linux that watches live network traffic and pairs anomaly detection with behavioural rules to surface suspicious activity as it happens.

Security Python Anomaly detection

An SSH deception system built with Python and Paramiko that safely captures attacker credentials, commands and behaviour, written for SOC and DFIR labs that want real attack traffic without real risk.

Security Paramiko DFIR

AI / ML Python Embeddings

Converts Ren'Py visual novels into the asset formats and scripting language that VNDS expects, which is how I get desktop games running on a DS flash card.
